# .github

Organization-wide files for [Happy Dwarf Team](https://github.com/happy-dwarf-team).

- [`profile/README.md`](profile/README.md) is shown on the organization page.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`CONTRIBUTING.md`](CONTRIBUTING.md),
  [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md), the issue forms and the
  pull request template in [`.github/`](.github) are the defaults for every
  repository of the organization that does not have its own file of that kind.
- [`docs/workshop-pages.md`](docs/workshop-pages.md) is the convention for Steam Workshop titles and
  descriptions of the team's mods and Anvil plugins.
- [`tools/workshop-thumbnail/`](tools/workshop-thumbnail) generates the Workshop preview image of an
  Anvil plugin in the Anvil website's style.
- [`tools/social-preview/`](tools/social-preview) generates the GitHub social preview image of a
  team repository in the same style.
