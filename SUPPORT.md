# Getting help

- **Installing Anvil and its plugins:** the guide and plugin catalog at
  [anvil.happydwarf.dev](https://anvil.happydwarf.dev).
- **Writing a plugin:** the author docs on the same site and the
  [plugin template](https://github.com/happy-dwarf-team/anvil-plugin-template).
- **A bug or an idea:** open an issue in the repository it concerns. Problems
  that also happen with no plugins loaded belong to
  [Anvil](https://github.com/happy-dwarf-team/anvil/issues/new/choose).
- **A security problem:** report it privately, see
  [SECURITY.md](SECURITY.md).
- **Behaviour in the community:** see the
  [code of conduct](CODE_OF_CONDUCT.md).

These are volunteer projects, so answers can take a few days.
