## Happy Dwarf Team

Open-source tools and mods for **Europa Universalis IV**, for players, mod authors and plugin
authors. They work beside the game, not inside its files.

Our main project is **[Anvil](https://anvil.happydwarf.dev)**, a plugin loader that lets
native plugins improve the game without changing `eu4.exe`, so Steam updates and file
verification keep working.

**All projects: [happydwarf.dev](https://happydwarf.dev)**

### Get involved

Bug reports and ideas go to the issues of the project they concern. Each repository's
`CONTRIBUTING.md` explains how to send a change, `SECURITY.md` how to report a vulnerability
privately, and `SUPPORT.md` where to ask for help.
