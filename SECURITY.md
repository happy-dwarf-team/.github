# Security policy

This is the default policy for Happy Dwarf Team repositories that do not have
their own `SECURITY.md`. Anvil and its plugins run inside the game process, so
please report security problems privately, not in public issues.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting in the affected repository:
**Security → Report a vulnerability** (the address is
`https://github.com/happy-dwarf-team/<repository>/security/advisories/new`).
Include the version you use, how to reproduce the problem, and what an
attacker gains.

This is a volunteer project; reports are handled on a best-effort basis. We
will confirm the report, agree on a fix and a disclosure date with you, and
credit you in the advisory unless you prefer otherwise.

## Supported versions

Only the latest release of each project receives security fixes.

## Out of scope

- Vulnerabilities in Europa Universalis IV itself; report those to Paradox
  Interactive.
- Antivirus detections of a release; open a regular issue with the detection
  name instead.
